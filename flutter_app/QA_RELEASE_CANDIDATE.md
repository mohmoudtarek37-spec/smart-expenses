# حساباتي 2.0 — دليل تجربة النسخة الشاملة (Release Candidate)

**الغرض:** دي نسخة للتقييم على موبايل أندرويد قبل النشر العام. نراجع كل
الوظائف الفعلية، ولا نعتبر خدمات خارجية غير مفعلة «تعمل» لمجرد ظهور زرها.

## نظام البيانات في النسخة النهائية

- **ضيف:** بيانات المعاملات والأقساط محفوظة على الجهاز في مساحة خاصة بالتطبيق
  باستخدام Flutter Secure Storage. لا تتم مزامنتها بحساب Supabase.
- **حساب مسجل:** نسخة محلية مشفرة ومعها مزامنة محافظة على الإصدارات إلى
  Supabase تحت نفس حساب المستخدم. المزامنة قد تتوقف دون فقد النسخة المحلية
  عند انقطاع الإنترنت أو اختلاف نسختين؛ لا يمكن اعتبارها مضمونة قبل اختبار جهازين.
- لا يُدمج دفتر الضيف بدفتر الحساب تلقائيًا. فيه خيار نقل مؤكد إلى **حساب فارغ**
  فقط، ويحتفظ بالأصل.
- Supabase هو التخزين المستضاف الخاص بالمشروع، وليس هاتف صاحب التطبيق.
  مالك المشروع صاحب صلاحيات إدارة واسعة. بيانات السحابة ليست مشفرة تشفير
  طرف لطرف بكلمة لا يعرفها إلا المستخدم؛ يجب حماية أذونات الإدارة والخصوصية.
- نسخة المتجر تُبنى الآن بــ `REQUIRE_ACCOUNT=false` زي نسخة التقييم:
  التسجيل **اختياري**، وليس فرضًا على كل المستخدمين.

## checklist لتقييم واجهة ووظائف التطبيق

### A. البداية والمظهر
- [ ] أيقونة H والمحفظة تظهر خارج التطبيق باسم Hesabaty
- [ ] الشعار يظهر في أعلى التطبيق
- [ ] العربية والإنجليزية: اختبر الرئيسية، المعاملات، الأقساط، التحليلات، الإعدادات
- [ ] الوضع الفاتح والداكن، وإغلاق التطبيق وفتحه مرة تانية يحفظ الاختيارات
- [ ] شاشة أندرويد صغيرة: الأزرار والنصوص بدون تداخل أو قص

### B. استخدام كضيف (محلي فقط)
- [ ] افتح كتجربة ضيف، أضف إيداع 500 ومصروف 50
- [ ] الإجمالي يعرض إيداع 500، سحب 50، متبقي 450
- [ ] اقفل التطبيق وافتحه، تفضل الأرقام والمعاملات موجودة
- [ ] تعديل المعاملة وحذفها واستبعادها يغير الإجماليات بشكل صحيح
- [ ] صدّر JSON واحفظ نسخة في مكان آمن
- [ ] **ممنوع حذف بيانات التطبيق** قبل التحقق من النسخة الاحتياطية

### C. حساب مسجل ومزامنة السحابة
- [ ] إنشاء حساب جديد بإيميل وباسورد والدخول دون تفعيل رسالة
- [ ] خروج ودخول بنفس الحساب والبيانات المحلية تظل معزولة عن الضيف
- [ ] أضف مصروفًا تجريبيًا، افتح الإعدادات وشاهد حالة المزامنة
- [ ] وافق على الرفع السحابي عند الحاجة؛ يظهر تأكيد نجاح الرفع
- [ ] راجع في Supabase وجود صف في `user_snapshots` للمستخدم
- [ ] افتح الحساب على موبايل تاني أو محاكي جديد واسترجع نفس المعاملة
- [ ] عدّل الجهازين بالتتابع؛ تأكد إنه يرفض الكتابة فوق نسخة أحدث
- [ ] افصل الإنترنت، احذف آخر معاملة، وارجع متصلًا؛ لا تعود نسخة قديمة
- [ ] جرّب نقل بيانات الضيف لحساب فارغ فقط، دون حذف بيانات الضيف
- [ ] جرّب حسابًا مختلفًا؛ لا تظهر له معاملات الحساب الأول

### D. الوظائف المالية
- [ ] إضافة/تعديل/حذف إيداع ومصروف، مع ملاحظات ومصدر وتصنيف
- [ ] تصنيفات مخصصة؛ تغيير اللغة لا يغير البيانات المخزنة
- [ ] صورة إيصال وإزالة/استبدال الصورة
- [ ] إنشاء قسط، تعديله، تسجيل دفعة، إلغاء دفعة
- [ ] التقسيم على الشهور، التواريخ، ومواعيد الأقساط المتأخرة
- [ ] تحليل المصروفات والمقارنة الشهرية

### E. الوظائف اللي مش جاهزة للإنتاج حاليًا
- [ ] **Reset Password**: يحتاج Gmail/SMTP ثم تجربة وصول الرابط للهاتف
- [ ] **Google Login**: يحتاج إعداد OAuth في Google Cloud وSupabase
- [ ] **Premium**: يحتاج Google Play Console، نشر الاشتراك، وربط API والتحقق الحقيقي
- [ ] **Push/background notifications**: غير منفذة؛ إشعارات التقويم تحتاج
      أن المستخدم يستورد ملف ICS ويشغّل تنبيهات التقويم
- [ ] **الحذف النهائي للحساب**: صفحة طلب الحذف موجودة، لكن تنفيذ الطلب
      والتحقق من هوية صاحبه يحتاجان سياسة دعم وتشغيل فعلي
- [ ] **اختبار Play Store**: مفتاح توقيع وإعداد Data Safety وسياسة الخصوصية
      وGoogle Play Internal Testing

## تسجيل العيوب

انسخ النموذج ده مع كل مشكلة:

- **الشاشة:** الرئيسية / المعاملات / الأقساط / التحليلات / الإعدادات / التسجيل
- **اللغة والمظهر:** عربي أو إنجليزي — فاتح أو داكن
- **كنت بعمل إيه؟** وصف الخطوات
- **المفروض يحصل إيه؟** النتيجة المتوقعة
- **حصل إيه فعلًا؟** النتيجة
- **صورة أو فيديو (بدون بيانات مالية حساسة):** رابط أو ملف
- **نوع الموبايل وإصدار أندرويد:** عند الإمكان

## تنزيل نسخة المراجعة

افتح GitHub Actions على فرع `flutter-v2`، ثم أحدث تشغيل ناجح باسم
`Flutter V2 Android and iOS Foundation`، وحمّل artifact
`hesabaty-flutter-v2-android-cloud-preview`.

هذه النسخة **debug/review** وليست APK نشر رسمي. نسخة Google Play تحتاج
توقيع AAB واختبارات إضافية. لا تستخدم بيانات مالية حقيقية قبل اجتياز اختبار
المزامنة والاستعادة على جهازين.
