# Hesabaty Android brand assets

The approved logo is the image provided by the product owner on 2026-10-17,
with the black H / green wallet and Hesabaty wordmark on white.

`branding/hesabaty_launcher.webp` is a small, launcher-only crop of its
**symbol**, without the wordmark so it stays legible on Android home screens.
The logo artwork is not being redesigned.

During each GitHub preview and signed release build:
- `flutter create` generates the Android platform resources.
- `tool/install_launcher_icon.py` replaces all standard mipmap launcher icons,
  creates an Android adaptive foreground, and sets a white adaptive background.
- `tool/ensure_android_internet.dart` sets the Android app label to Hesabaty.

When the owner supplies a revised final logo, replace the approved artwork
and regenerate the launcher-only crop, without changing cloud users or data.

**Do not manually modify the default Flutter icon:** it gets regenerated by
`flutter create` during CI. The installer is the source of truth.
